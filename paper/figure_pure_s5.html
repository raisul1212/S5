Pure S5 layer architecture: main state-space model only, with two output-activation variants (GELU and rank-r half_glu2)

main SSM path GELU (variant A) gated output (variant B) Mambino additions (not in Pure S5)

Figure 1-baseline. One Pure S5 layer — the baseline against which Mambino is defined. Input x[t] feeds a single input-projection matrix B to produce the main SSM input Bu = B·x. The main SSM runs a bidirectional associative scan (forward + backward, concatenated along local_P), then the output projection C collapses the state back to the hidden dimension H. The output activation splits into two variants: variant A uses a pointwise GELU (no gate matrices — used by Config 5, P = 16); variant B uses the canonical LRA S5 recipe with a full-rank half_glu2 gate Dense(H, H) (Corner 1, P = 8). Compared to Figure 1 (Mambino), this baseline lacks the entire predictor SSM branch and the additive W_ε feedback loop (dashed-orange callout, top right). Those two additions — a second, forward-only SSM predicting x[t] from past inputs and an additive projection of the resulting surprise ε = x − pred back into Bu — are Mambino's isolated architectural contribution.
